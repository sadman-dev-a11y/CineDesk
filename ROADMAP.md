# Roadmap

Release hardening: verify Supabase policies and auth flows on a real project, complete shared production-tool persistence, add secure invitations and role administration, private file UI, profile/avatar management, budget category plans, schedule revisions, and durable call-sheet records.

Subsequent production features: advanced stripboard scheduling, availability/equipment conflict detection, screenplay import improvements, document versioning, production analytics, notifications, and post-production collaboration.

Longer term: optional AI screenplay breakdown, scheduling assistance, Android client, English/Bangla localization, and carefully scoped encrypted offline access. These are planned capabilities, not implemented release features.
